UNTUNGIN — versi awal PWA
================================
Ini adalah prototipe aplikasi web installable (PWA), bukan APK native dan belum memuat iklan aktif.

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Unggah seluruh isi folder ke hosting HTTPS yang mendukung file statis.
3. Buka alamat hosting dari Chrome Android.
4. Pilih menu Chrome (titik tiga) > Tambahkan ke layar utama / Install app.

CATATAN:
- Service worker dan PWA memerlukan HTTPS (localhost untuk pengujian).
- Slot iklan di beranda masih placeholder. Iklan AdMob belum aktif.
- Untuk AdMob perlu membuat akun, mendaftarkan aplikasi, memperoleh App ID dan Ad Unit ID, mengintegrasikan SDK yang sesuai, memasang app-ads.txt bila diwajibkan, dan memenuhi kebijakan serta proses peninjauan Google.
- Jangan klik iklan sendiri atau meminta pengguna mengeklik iklan.
- Ganti alamat email contoh di halaman Profil sebelum publikasi.
- Tambahkan kebijakan privasi dan mekanisme penghapusan/penanganan data sebelum rilis publik.
